# EduHisob — учёт платежей учебного центра

Тестовое задание Ecomdev, интерфейс B: должники и добавление платежа. Существующий FastAPI API и Telegram-бот сохранены. Сайт на узбекском языке использует Jinja2, HTML, CSS и обычный JavaScript. Один сервер обслуживает страницы, статические файлы, API и Swagger; Node.js и отдельный frontend-сервер не нужны.

## Установка с нуля

Нужен Python 3.12 или новее. Откройте терминал в каталоге проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```

Если `.env` уже существует, сохраните его: повторное копирование не требуется. Пустой `BOT_TOKEN` не мешает работе сайта. SQLite-файл `education.db` и таблицы создаются автоматически при старте. Для другой SQLite-базы задайте `DATABASE_URL` в `.env`. Запускайте команды из корня проекта, чтобы путь к базе оставался одинаковым.

- Сайт: http://127.0.0.1:8000/
- Swagger: http://127.0.0.1:8000/docs
- OpenAPI: http://127.0.0.1:8000/openapi.json

Для просмотра с телефона в одной локальной сети замените `--host 127.0.0.1` на `--host 0.0.0.0` и откройте `http://IP-КОМПЬЮТЕРА:8000/`. Используйте доверенную локальную сеть: авторизации пока нет.

## Использование

1. В разделе «O‘quvchilar» нажмите «O‘quvchi qo‘shish» и укажите имя, телефон, группу и месячный тариф. Там же доступны поиск, редактирование, история и удаление с подтверждением. Удаление ученика удаляет его платежи.
2. Вверху выберите отчётный месяц. Главная показывает сумму всех платежей этого месяца, сумму положительных долгов и число должников.
3. В разделе «Qarzdorlar» найдите ученика по имени или группе. Кнопка «To‘lov qo‘shish» автоматически выбирает ученика.
4. На форме оплаты можно искать по ID, имени или телефону. Укажите положительную сумму с максимум двумя знаками после точки и дату. По умолчанию дата соответствует сегодняшнему дню в Asia/Tashkent.
5. После сохранения открывается история ученика. Месяц отчёта переключается на месяц платежа; при переходе на главную или к должникам загружаются актуальные данные.

Начальная база пустая; демонстрационные данные автоматически не добавляются. Для знакомства создайте ученика через интерфейс.

## API и точность

Сохранены `POST/GET /students`, `GET/PATCH/DELETE /students/{id}`, `POST /payments`, `GET /students/{id}/payments`, `GET /debtors?month=YYYY-MM`. Добавлен `GET /summary?month=YYYY-MM`: `paid_amount`, `debt`, `debtor_count`, `month`.

Деньги хранятся целыми тийинами; суммы и долги рассчитывает backend с Decimal. Передавайте суммы строками, например `"100.30"`, чтобы избежать float. Долг = текущий месячный тариф минус платежи только за выбранный календарный месяц. Не платившие входят в список; полностью оплатившие и переплатившие не входят. Переплата одного ученика не уменьшает долг другого. Общая сумма оплаты включает переплаты. Платёж другого месяца не переносится на выбранный месяц.

## Telegram-бот

Необязательный отдельный процесс. Сначала запустите API, затем задайте настоящий `BOT_TOKEN` в локальном `.env` и выполните:

```bash
source .venv/bin/activate
python -m bot.main
```

`API_BASE_URL` по умолчанию `http://127.0.0.1:8000`. Команды: `/start`, `/debt` (текущий месяц Ташкента), `/pay 1 150000.50`. Бот обращается к API по HTTP. Токен не передаётся в HTML/JavaScript.

## Проверки

```bash
source .venv/bin/activate
python -m pytest -q
```

Тесты используют отдельные временные SQLite-базы. Покрыты CRUD, каскадное удаление, точное хранение денег, валидация, границы месяцев, частичная/полная оплата и переплата, бот, новая статистика и выдача страницы/ресурсов.

Необязательная проверка настоящим браузером (нужен установленный Google Chrome по пути `/usr/bin/google-chrome`):

```bash
python -m pip install playwright==1.63.0
python scripts/browser_e2e.py
```

Сценарий использует временную базу и ASGI transport, не затрагивает рабочие данные. Проверяет создание → частичную оплату → уменьшение долга → полную оплату → исчезновение из должников, ошибки нулевой суммы и отсутствие горизонтального переполнения на 1366 и 360 px. Снимки сохраняются в `/tmp/education-1366.png` и `/tmp/education-360.png`. Текущий фактический результат и ограничения среды: [docs/VERIFICATION.md](docs/VERIFICATION.md).

## Ограничения

- Нет авторизации и разграничения доступа; приложение предназначено для локального тестового использования.
- Тариф текущий: изменение месячной платы влияет и на расчёт прошлых месяцев. Нет даты зачисления, архивирования, тарифной истории или переноса переплат между месяцами.
- Удаление ученика каскадно удаляет историю; нет отмены и аудита. Платежи нельзя редактировать/удалять через интерфейс.
- Списки загружаются целиком; нет пагинации. Изменения из другого браузера или бота видны после повторного открытия раздела/обновления.
- Нет защиты от повторной оплаты после сетевого таймаута: кнопка блокируется на время запроса, но перед ручным повтором следует проверить историю.
- SQLite и автоматическое создание таблиц без миграций; поддержка других СУБД не заявляется.
